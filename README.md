# Security Automation Framework

An automated security alert triage and response framework using:

- Wazuh
- Python
- VirusTotal
- SOAR
- Notifications
- Audit Logging

## Project Workflow

Wazuh → Python → VirusTotal → Risk Engine → SOAR → Notification → Audit Log
